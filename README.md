# CHAOSVERSE

CHAOSVERSE is an interactive React entertainment site filled with pranks, comedy, games, memes, surprises, and hidden rooms.

## Features

- Animated boot screen and page transitions
- Prank Lab and comedy experiences
- Chaos Games and random surprises
- Meme Factory
- Secret Room and Easter eggs
- Responsive, dark neon visual design
- Reduced-motion support and keyboard-accessible navigation

## Getting started

### Requirements

- Node.js 18 or newer
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open the local URL shown by Vite in your browser.

### Production build

```bash
npm run build
npm run preview
```

## Routes

| Route | Experience |
| --- | --- |
| `/` | Home |
| `/prank-lab` | Prank Lab |
| `/comedy` | Comedy World |
| `/games` | Chaos Games |
| `/surprises` | Random Surprises |
| `/meme-factory` | Meme Factory |
| `/secret` | Secret Room |

## Tech stack

- React
- Vite
- React Router
- Framer Motion
- Tailwind CSS
- Lucide React

## Deployment

The project includes a `vercel.json` configuration and can be deployed to Vercel after connecting the repository.
